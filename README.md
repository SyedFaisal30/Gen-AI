# 🚀 GenAI Learning Journey by Syed Faisal

Welcome to my **GenAI Self-Learning Repository**, where I’ve documented my journey to mastering cutting-edge concepts in Generative AI, LLMs, LangGraph, RAG, and tool-based orchestration — all in a structured, step-by-step format.

> 📚 **If you're new to GenAI or RAG and want to learn in a guided, hands-on way — follow this repo step-by-step, just like I did!**

## 🧠 What’s Inside?

Each folder represents a **dedicated concept I explored**, from foundational theory to advanced orchestration. You’ll find:
- 📒 Notes
- 🧪 Examples
- 📁 Reference files (PDFs, DOCX)
- 🧠 Thought process and reasoning-based explanations

### 📂 Step-by-Step Learning Path

| Step | Folder | What You’ll Learn |
|------|--------|-------------------|
| 1️⃣ | `1_Step_GENAI` | Basics of GenAI, Tokenization, Transformers, Embeddings |
| 2️⃣ | `2_Step_RAG` | Introduction to RAG (Retrieval-Augmented Generation), Chunking, Vector Stores |
| 3️⃣ | `3_Step_ADV_RAG` | Advanced RAG Techniques – HyDE, Fusion, Query Decomposition, RRF |
| 4️⃣ | `4_Step_Routing` | Query Routing – Semantic vs Logical, Router Agents |
| 5️⃣ | `5_Step_Web` | Building Web Apps for GenAI Systems (LangChain, UI, APIs) |
| 6️⃣ | `6_Step_Chat_Memory` | Chat Memory – Buffer, Summary, Combined Types |
| 7️⃣ | `7_Step_LangGraph` | LangGraph Framework – Node-based Reasoning, Flow Design |
| 8️⃣ | `8_Step_CheckPointing` | Checkpointing using MongoDB – Safe Recovery & Debugging |
| 9️⃣ | `9_Step_MCP` | MCP Protocol – Multi-Agent, Human-in-the-Loop, A2A, OpenID Connect |
